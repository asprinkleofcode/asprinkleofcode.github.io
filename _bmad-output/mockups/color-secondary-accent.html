Secondary accent — 3 options on the locked palette

Neutrals, rose brand, and status colors are fixed (from the repo theme + tuned defaults). Only the secondary accent changes below. Proposed role: the rose stays the identity / brand colour (name, primary CTA, focus); the secondary carries functional emphasis — capability signals, secondary CTAs, in-page highlights, "explore" affordances — so it never competes with professional evidence.
