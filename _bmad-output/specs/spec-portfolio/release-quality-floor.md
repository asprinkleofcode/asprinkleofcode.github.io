# Production-Quality Floor

The gate every publicly available version must clear. Referenced by the no-public-release-below-the-floor constraint and the Success signal. Source: `PRD.md` NFR-4 (D-12).

Any version made publicly available must meet **all** of:

- Core journeys work end-to-end.
- No known critical accessibility issues (target: WCAG 2.2 AA).
- Responsive experience works across supported mobile and desktop viewport sizes.
- No obviously broken or placeholder content.
- Professional content is public-safe (see `professional-storytelling.md`).
- Basic performance and discoverability requirements are met.

Incomplete or intentionally experimental work stays non-public until it meets this floor.
